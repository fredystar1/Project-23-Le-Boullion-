    Function findAndShortenFirstParagraph

    • findAndShortenFirstParagraph(contentArray: any[], maxLength?: number): string

      Find the first paragraph node inside a Storyblok rich-text content array and return its text, truncated to maxLength characters.

      This is used by EventListItem to show a brief preview of an event's description without rendering the full rich-text tree.

      Parameters

      • contentArray: any[]

        The content array from a Storyblok rich-text field.

      • maxLength: number = 300

        Maximum character count before truncation (default 300).

      Returns string

      The extracted (and possibly truncated) plain-text string, or "" if no paragraph is found.

      Example

      findAndShortenFirstParagraph(blok.event_description.content, 120);
      // → "Join us for a night of fine wine tasting featuring..."
